❓ TROUBLESHOOTING RAPIDO

ERROR: "psql not found"
  CAUSA: PostgreSQL no está en PATH
  SOLUCION: Agrega C:\Program Files\PostgreSQL\15\bin al PATH

ERROR: "database sistema_ot does not exist"
  CAUSA: Base de datos no fue creada
  SOLUCION: psql -h localhost -U postgres -f database/sistema_OT_BD_v3.sql

ERROR: "relation op_orden_trabajo does not exist"
  CAUSA: Tablas base no existen
  SOLUCION: Ejecuta el script base de BD primero

ERROR: Conexión rechazada
  CAUSA: PostgreSQL no está corriendo
  SOLUCION: Inicia el servicio PostgreSQL

ERRROR: Contraseña incorrecta
  CAUSA: Contraseña no coincide
  SOLUCION: Edita PGPASSWORD en los scripts

Para MAS AYUDA, consulta MIGRACIONES.md en la carpeta database/
