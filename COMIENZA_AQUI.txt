❓ PREGUNTAS FRECUENTES

P: ¿Cuánto tiempo toma ejecutar las migraciones?
R: Menos de 5 segundos. Es una operación muy rápida.

P: ¿Es seguro ejecutar múltiples veces?
R: Sí. Los scripts usan CREATE TABLE IF NOT EXISTS, así que son idempotentes.

P: ¿Qué pasa si algo falla?
R: Las migraciones usan transacciones, así que se revierten automáticamente.
   Verifica el error en MIGRACIONES.md > Troubleshooting.

P: ¿Puedo cambiar la contraseña de PostgreSQL?
R: Sí. Edita PGPASSWORD en los scripts batch/PowerShell.

P: ¿Qué son los triggers?
R: Funciones que se ejecutan automáticamente en la BD:
   • Trigger 1: Valida máximo 10 acompañantes
   • Trigger 2: Valida campos obligatorios en purgado

P: ¿Debo hacer algo especial en el backend?
R: Sí, después de la migración debes crear entidades JPA para que Hibernate
   las mapee correctamente. Ver MIGRACIONES.md > Próximos pasos.

📞 TROUBLESHOOTING RAPIDO

ERROR: "psql not found"
  → Agrega C:\Program Files\PostgreSQL\15\bin al PATH
  → Reinicia CMD o PowerShell

ERROR: "database sistema_ot does not exist"
  → Ejecuta: psql -h localhost -U postgres -f database/sistema_OT_BD_v3.sql
  → Luego intenta nuevamente

ERROR: "relation op_orden_trabajo does not exist"
  → Las tablas base no se crearon
  → Ejecuta primero la BD base (sistema_OT_BD_v3.sql)

ERROR de conexión
  → PostgreSQL no está corriendo
  → Windows: Abre Services.msc y busca PostgreSQL
  → Haz click derecho > Iniciar

ERRROR de contraseña
  → Verifica que la contraseña sea correcta en application.properties
  → Actualiza PGPASSWORD en los scripts

Para MAS AYUDA:
  → Lee el archivo MIGRACIONES.md en la carpeta database/
